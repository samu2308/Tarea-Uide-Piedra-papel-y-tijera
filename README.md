El juego Piedra, Papel o Tijera está codificado en Python de forma modular para que el código sea fácil de entender. En el archivo datos se definen las estructuras principales, como una tupla con las posibles opciones del juego y un diccionario con las reglas de victoria. El archivo entradas gestiona la interacción con el usuario, validando la opción ingresada y generando la elección aleatoria de la computadora. En lógica se compara la elección del jugador con la de la computadora para determinar si hay empate, victoria o derrota. Finalmente, Juego maneja el flujo principal con un bucle que se repite hasta que el usuario desee terminar, usando funciones, condicionales y estructuras de datos básicas para su ejecución correcta y completa.
