El programa Piedra, Papel o Tijera está desarrollado en Python y organizado en varios archivos para facilitar su comprensión y orden. Cada archivo cumple una función específica dentro del funcionamiento del programa.
En datos.py se definen las opciones del juego mediante una tupla, ya que estas no cambian, y un diccionario que contiene las reglas de victoria.
En entradas.py se gestionan las entradas del jugador y la elección aleatoria de la computadora, validando que la opción ingresada sea correcta.
En logica.py se compara la elección del jugador con la de la computadora para determinar si el resultado es empate, victoria o derrota.
Finalmente, en Juego.py se controla el flujo del programa mediante un bucle que permite repetir el juego hasta que el usuario decida finalizarlo.
Este proyecto permite aplicar conceptos básicos de programación como funciones, condicionales, bucles y estructuras de datos, demostrando la relación entre los diagramas de flujo y el código.
